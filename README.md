## 📱 About the App

Marketi is a Flutter e-commerce application that allows users to browse products, create accounts, and manage authentication flows.

It uses Cubit for state management and follows clean architecture principles.


## ✨ Features

- User authentication (Login / Signup)
- Password reset & verification
- Onboarding screens
- Clean UI design
- State management using Cubit
